# Thème VELEA – ceinture chauffante pour règles

Fichiers modifiés ou ajoutés par rapport à Dawn 16.0.0 (thème Shopify officiel).
Tout le reste du thème est Dawn d'origine.

- `assets/velea.css` : direction artistique (crème, rose poudré, framboise, corail).
- `sections/vl-*.liquid` : sections de vente (bannière, bloc d'achat avec offres, mode d'emploi, comparatif, FAQ…).
- `snippets/vl-*.liquid` : logo, icônes, illustration de la ceinture.
- `templates/*.json`, `sections/*-group.json`, `config/settings_data.json` : contenus et réglages.

Les templates sont générés par `../velea-theme-tools/content.py` (textes de vente).
Les visuels produit sont dessinés dans `../velea-theme-tools/visuals.html` et exportés avec `render.mjs`.
