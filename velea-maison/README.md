# VELEA Maison – thème premium

Thème Dawn 16.0.0 d'origine + fichiers VELEA ci-dessous. Tout le reste est Dawn non modifié.

- `assets/maison.css` : direction artistique (porcelaine rosée, bordeaux nuit, pivoine, Bodoni Moda + Instrument Sans).
- `sections/vx-*.liquid` : ouverture, trois chaleurs (élément signature), achat avec offre duo, une séance,
  comparatif, caractéristiques, avis (réels uniquement), engagements, questions, dernier mot, barre d'achat.
- `snippets/vx-*.liquid` : logo, emblème, icônes, marges.
- `layout/theme.liquid`, `sections/header.liquid` : Dawn + feuille de style et logo VELEA.
- Contenus générés par `../velea-maison-tools/content.py`.
