## 📝 À faire de ton côté (dans l'admin Shopify)

### 1. Produits
- [ ] Ajouter **les photos** de chaque produit (fond uni crème/noir = rendu luxe)
- [ ] Vérifier/ajuster **prix, descriptions, liste d'ingrédients (INCI)** selon tes vrais produits
- [ ] Renseigner le **stock** et le **poids** (pour le calcul des frais de port)
- [ ] Passer les produits de *Brouillon* à *Actif*

> Cosmétiques en France/UE : l'étiquette doit respecter le règlement (CE) n°1223/2009 (liste INCI, personne responsable, n° de lot, PAO…). Vérifie ça avec ton fournisseur.

### 2. Design (Boutique en ligne → Thèmes → Personnaliser)
Palette luxe conseillée :
| Rôle | Couleur |
|---|---|
| Fond | `#FAF7F2` (ivoire) |
| Texte / boutons | `#111111` (noir) |
| Accent | `#B8975A` (or) |
| Fond secondaire | `#EFE8DD` (sable) |

- Polices : **Cormorant Garamond** (titres) + **Montserrat** ou **Jost** (texte)
- Page d'accueil suggérée :
  1. Bannière plein écran + « Découvrir la collection » → Best-sellers
  2. Collections en vedette : Visage / Corps / Rituels Bien-être
  3. Grille produits : Best-sellers
  4. Image avec texte : « L'art du soin, réinventé » → À propos
  5. Bloc Coffrets Cadeaux
  6. Réassurance : Livraison offerte dès 60 € · Paiement sécurisé · Retours 14 jours
  7. Inscription newsletter (−10 % sur la 1re commande)
- Ajouter ton **logo** et un **favicon**
- Barre d'annonce : « Livraison offerte dès 60 € d'achat »

### 3. Paramètres
- [ ] **Paiements** : activer Shopify Payments (+ PayPal si souhaité)
- [ ] **Expédition** : créer les tarifs annoncés sur la page Livraison
  - France : 4,90 € (gratuit dès 60 €), point relais 3,90 €
  - Europe : 9,90 €
- [ ] **Taxes** : TVA française 20 % (vérifier selon ton statut : micro-entreprise en franchise de TVA = pas de TVA facturée)
- [ ] **Politiques** (Paramètres → Politiques) : générer CGV, confidentialité, remboursement, expédition
- [ ] **Mentions légales** : compléter les `[...]`, publier la page puis l'ajouter au menu du pied de page
- [ ] **Notifications e-mail** : ajouter le logo et vérifier les textes
- [ ] **Nom de la boutique** : remplacer « Ma boutique » par ton nom de marque
- [ ] **Domaine** : acheter/connecter ton nom de domaine

### 4. Avant d'ouvrir
- [ ] Passer une commande test (mode test Shopify Payments)
- [ ] Vérifier l'affichage sur mobile
- [ ] Retirer le mot de passe de la boutique (Préférences → Protection par mot de passe)
